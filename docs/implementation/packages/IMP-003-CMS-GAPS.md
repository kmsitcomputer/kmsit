# IMP-003 — CMS Gap Closure

## Preserve
Articles, News, Tutorials, Activities, Pages, Tiptap, Media, Homepage Builder, Menu, SEO.

## In scope
Reconcile locked baseline against approved CMS requirements. Evaluate Banner/Slider/FAQ/Testimonial/Landing Page against existing generic blocks/content model before adding new tables/modules. Implement safe draft/preview/publish only where confirmed.

## Rules
Prefer extending generic content/block mechanisms when semantically correct. Do not duplicate content systems. Preserve sanitization and backend authorization.
